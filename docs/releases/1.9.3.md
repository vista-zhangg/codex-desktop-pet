# AgentPaw · AI 桌伴 1.9.3

1.9.3 改进任务提醒与行动中心，让多个 AI 编程任务更容易查看和处理。原有权限、用量、额度、角色、休息提醒与隐私功能继续可用。

## 任务提醒更克制

- 「标准」模式会立即提示待处理事项，将连续完成合并为一次提醒，并延迟确认短暂错误。
- 「仅需处理」模式隐藏普通问候和完成气泡，继续提示等待授权、等待回复与持续错误。
- 可按 Agent 或项目静音。静音只影响自动提醒；待处理计数、权限卡和 Agent 状态仍保留，方便手动查看。
- 短暂错误恢复或会话关闭后，不再补发过期错误提醒。开启新一轮任务时，取消上一轮尚未显示的完成气泡。

## 行动中心与会话

- 从桌宠旁的行动中心查看待处理事项、最近 7 天最多 100 条事件，以及当前和已关注的会话。
- 查看完成、持续失败和曾经需要处理的事件；支持已读、全部已读、清空和返回对应任务。
- 为会话设置别名或关注；工作速览优先显示待处理和正在运行的任务。已结束的关注会话不会遮住当前任务。
- 最近事件只保留本机摘要，不复制提示词、回复、命令或权限内容。清空历史不会取消仍在等待的授权或回复请求。

## 可选快捷键

可为工作速览、下一个待处理任务和桌伴显示／隐藏分别设置全局快捷键；默认全部停用，不设置也可正常使用。为避免常见操作冲突，只接受 `Ctrl+Shift` 或 `Ctrl+Alt` 与按键的组合；设置窗口获得焦点时会暂停全局绑定。不同软件内部仍可能使用相同组合，请选择不常用的按键。快捷键不会替用户作出授权决定。

## 下载与升级

仅支持 **Windows x64**。从本页下载 **`AgentPaw-1.9.3-Windows-x64.exe`**，也可通过应用内更新升级。`latest.yml` 由应用更新器读取，无需手动下载。

首次运行的 SmartScreen 提示与以前的 Windows 版本相同。会话偏好、提醒设置和最近记录保存在本机 `~/.agentpaw/`；隐私模式会隐藏对应名称和别名。

## English

AgentPaw 1.9.3 makes task notifications quieter and adds a recent-events view to the action center. Choose Standard or Needs attention only, combine nearby completion notices, and defer transient failures. Muting an agent or project affects automatic notices while its state and pending permission cards remain available.

The action center keeps up to 100 local event summaries for seven days, with read controls and links back to tasks. Sessions can have aliases and follow pins; current work and attention items stay ahead of ended sessions. History does not copy prompts, replies, commands, or permission contents, and clearing it does not dismiss a pending request.

Optional global shortcuts can open the work peek, move to the next attention item, or show/hide the pet. They are disabled by default. Configured bindings pause while Settings is focused. Global shortcuts can still overlap combinations used inside other software, so choose an uncommon combination. They never decide permissions.

Download `AgentPaw-1.9.3-Windows-x64.exe` or use the in-app updater. Windows x64 only; `latest.yml` is read by the updater. Local session preferences and event summaries remain under `~/.agentpaw/`.
