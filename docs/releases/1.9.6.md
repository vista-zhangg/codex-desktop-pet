# AgentPaw · AI 桌伴 1.9.6

1.9.6 优化桌宠弹窗布局、行动中心已读交互及设置入口，让查看任务和调整偏好更顺手。

## 更舒展的弹窗布局

- 休息提醒、工作速览、额度详情、选项面板和消息气泡根据内容调整宽度，减少多余空白，同时保留长文本换行和屏幕边界限制。
- 行动中心保留 320px 的舒适最小宽度，并增加内边距；工作速览保留 300px 的最小宽度，窄屏下可继续收缩。
- 行动中心页签保持单行，短内容更紧凑、信息较多时仍能自然展开。

## 查看最近记录即自动已读

- 打开行动中心并进入“最近”，或手动、键盘切换到该页签时，已有记录自动标记为已读，无需再点一次按钮。
- 移除“标为已读”和“全部已读”，保留打开会话与清空记录。
- 进入“待处理”或“会话”不会清除历史未读；停留期间新到记录仍保留未读，下次进入“最近”时确认。
- 已读不会处理待办或改变待处理数量；保存失败会提示，重新进入“最近”可重试。

## 设置更容易找到

- 宠物右键菜单、隐藏宠物后的胶囊右键菜单新增“设置”。
- 工作速览和行动中心右上角新增线框齿轮，悬停显示“设置”，支持键盘聚焦与操作。
- 点击入口后收起当前弹窗并打开设置；设置已经打开时直接唤到前台。
- 调整四按钮菜单的布局，保持屏幕边角下的按钮间距和可见范围。

## 下载与升级

仅支持 **Windows x64**。从本页下载 **`AgentPaw-1.9.6-Windows-x64.exe`**，也可通过应用内更新升级。`latest.yml` 由应用更新器读取，无需手动下载。

## English

AgentPaw 1.9.6 improves content-aware popup sizing while keeping comfortable minimum widths for the action center and work peek. Entering the Recent tab automatically marks existing records as read; newly arriving records and pending actions remain distinct. Manual read buttons have been removed, while session navigation and clearing history remain available.

Settings is now accessible from the pet and compact capsule context menus, as well as gear buttons in the work peek and action center headers. Existing settings windows are brought to the foreground. Menu placement and spacing are adjusted for the fourth action.

Download `AgentPaw-1.9.6-Windows-x64.exe` or use the in-app updater. Windows x64 only; `latest.yml` is read by the updater.
