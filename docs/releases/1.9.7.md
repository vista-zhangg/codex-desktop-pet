# AgentPaw · AI 桌伴 1.9.7

1.9.7 更新用量详情面板，用活动热图呈现使用节奏，统一工具与日期筛选，并保留缓存、Token、任务和历史累计信息。

## 更清晰的用量详情

- 新增最近 90 天 Token 活动热图、每周趋势及窗口累计视图，替换原有柱状趋势。窗口累计只统计图中保留的记录，与历史累计分开展示。
- 支持点击日期查看当日明细，并一键返回原来的统计周期；日历支持方向键导航。
- 今日、近 7 天、近 30 天及工具筛选统一作用于总量、缓存、Token 明细和消耗分布。近 7 天和近 30 天使用不含今日的完整自然日范围。
- 消耗分布支持按工具或模型查看，以 Token 或已记录金额排序；历史模型分布使用对应日期的台账。
- 保留当前任务、上下文、最近操作与历史累计；这些区域不受日期筛选影响，工具筛选仍然生效。
- 记住常用筛选，保留刷新时的日期选择与键盘焦点，适配最小宽度窗口。

## 更准确的统计口径

- 缓存率按缓存读取总量除以全部输入总量计算，不平均各次比例，也不重复计算已包含在输入中的缓存。
- 保留缓存读取、缓存写入及推理 Token；推理是输出的子集，不再计入总量。缓存写入区分 5 分钟、1 小时和未区分时长，避免将其他工具的普通写入误标为 5 分钟缓存。
- 区分无记录与明确的零用量；无输入或分项不完整时不推算缓存率。今日未结束、同期记录不完整或数据源不可用时不显示误导性的用量环比。
- 旧台账缺少完整的逐笔计价状态，费用覆盖率显示“未知”；零金额记录不视为免费。金额为已记录的参考金额，可能混合来源上报、公价折算和近似估算，不代表订阅账单。
- 计量记录沿用各来源原有计数规则，不等同于用户消息或统一对话轮次。部分后台请求仅计 Token、不计条数。
- 新增历史展示不重写原有台账；历史明细只发送给详情窗口，减少桌宠日常刷新时的数据传输。

## 下载与升级

仅支持 **Windows x64**。下载 **`AgentPaw-1.9.7-Windows-x64.exe`** 安装升级，或使用应用内更新。`latest.yml` 由更新器读取，无需手动下载。现有配置与本机用量记录继续保留。

## English

AgentPaw 1.9.7 adds a 90-day token activity heatmap, weekly trends, and window totals. Date drill-down and tool filters now apply consistently to usage totals, cache statistics, token details, and historical model distributions. Current tasks, context, recent operations, and lifetime totals remain available with clearly separated date scopes.

Cache ratios use aggregated token counts without double-counting cached input or reasoning output. Missing dates are distinguished from recorded zero usage; incomplete periods are not used for misleading comparisons. Historical pricing coverage is marked unknown when the ledger lacks per-record provenance, and zero recorded cost is not presented as free usage. Reference amounts are not subscription bills.

Download `AgentPaw-1.9.7-Windows-x64.exe` or use the in-app updater. Windows x64 only; `latest.yml` is read by the updater. Existing settings and local usage records are preserved.
