# AgentPaw · AI 桌伴 1.9.1

本次更新扩充奶茶鼠内置动图，让 Codex、Claude Code 等 AI 编程工具的任务状态拥有更多表情变化。

## 奶茶鼠表情扩充

- 在 1.9.0 的 15 张基础上新增 **69 张 GIF**，合计 **84 张**，覆盖 16 个工作、反馈与休息状态。
- 新增素材来自奶茶鼠 plus、plus3、plus4、plus5、plus6 与 PLUS7，按动作内容分配到思考、回应、等待、庆祝、闲时活动和下班等状态。
- 睡觉休息改用「睡觉」「困鼠」「哈欠」，替换此前的待命占位动作；思考状态使用「认真」「小心思」「踱步」。
- 设置页显示原表情名称，方便查找和调整。保留原背景、动画帧数和每帧时长，统一适配为 120×120。
- 新素材加入内置默认集合；已有角色及各状态的自定义编辑继续保留。使用了替换模式的状态可通过“恢复默认”切换到新版默认集合。
